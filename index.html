    Onde seus dados ficam

    Tudo fica no armazenamento local deste navegador, neste computador — os lançamentos, suas correções de categoria e a lista de arquivos já importados. Nada é enviado para nenhum servidor, e por isso também nada é sincronizado: em outro navegador ou outro computador a página abre vazia, e limpar os dados do site apaga tudo. Exporte a planilha para guardar em lugar seguro, e o backup se quiser levar as regras e o histórico para outra máquina.

    Quando você corrige uma categoria, a correção vira regra para aquele estabelecimento e vale para os próximos meses.
